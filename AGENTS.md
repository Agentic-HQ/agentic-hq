# AGENTS.md

This repository is built collaboratively with AI agents (primarily [Claude Code](https://www.anthropic.com/claude-code)).

If you are an AI agent running in this repo, the binding internal rules live in [CLAUDE.md](./CLAUDE.md). They apply to you — read CLAUDE.md before doing any work.

If you are a human contributor whose agent reads this file, the contributor-facing guide is [CONTRIBUTING.md](./CONTRIBUTING.md). [CLAUDE.md](./CLAUDE.md) is the source of truth for what we expect of agents and AI-assisted work in this repo.
